Connect your WordPress site to your KothaBot Voice AI assistant.

== Description ==

KothaBot Connect links your WordPress site to your KothaBot Voice AI assistant:

* **Embed the widget** — one toggle adds the voice/chat assistant to your site.
* **Sync WooCommerce products** — your catalog is pushed into the AI so it can answer about products and prices.
* **Sync page knowledge** — pick pages (About, FAQ, Services) to feed the AI.
* **Two-way orders** — new WooCommerce orders flow into KothaBot; voice/chat orders flow back to WooCommerce (Phase 2).
* **Two-way bookings (Amelia)** — keep appointments in sync (Phase 2).

= Setup =

1. In your KothaBot dashboard, go to Integrations → API Keys and create a live key.
2. Install & activate this plugin.
3. Go to Settings → KothaBot, paste your KothaBot URL + API key, and click "Save & Connect".
4. Turn on the syncs and the widget you want, then use "Sync now" for the first import.
